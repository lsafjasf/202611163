# 单摆 / 双摆物理仿真实验室

纯原生 ES Module 实现，无第三方依赖。浏览器负责 Canvas 绘制与 Web Audio 音效，
物理内核为定步长 RK4 积分，可在 Node 下直接验证。

## 运行

```bash
npm run serve        # 然后打开 http://localhost:8080
npm test             # 9 项物理测试 + 13 项界面交互断言
```

> 因使用 ES Module，需通过 HTTP 服务访问，不要用 `file://` 直接打开。

## 功能对照

- 参数调节：摆长、质量、初始角度（双摆含第二组参数），摩擦可开关。
- 实时轨迹：Canvas 绘制支点、摆杆、摆体与渐隐轨迹，越界区域红色虚线标注。
- 安全限值：速度 ≤ 5.5 m/s、支点压力 ≤ 1500 N、温度 ≤ 80 °C、负载 0.1–50 kg、
  世界边界 ±4.5 m；任一超限立即停止积分，面板报告触发点的位置、速度、压力、温度与当时能量。
- 控制：运行、暂停、单步（精确推进 1/60 s = 4 个 RK4 子步）、重置、回放。
- 暂停/单步/回放时绘制红色切向受力箭头（角加速度方向）与变化趋势。
- Web Audio：振荡器音高随当前最大速度在 110–880 Hz 间变化。
- 导出：轨迹 CSV 与含参数、限值、触发记录、连续性校验的 JSON。
- 面板实时显示关键物理量，并记录“最近一次参数变化”的字段、时间与配置摘要。

## 确定性与正确性保证

- 固定物理步长 `1/240 s`，不使用 `Date`/`Math.random` 驱动积分，同参数重复运行状态位级一致。
- 暂停与单步共用 `advanceFrame()` 同一条积分路径，物理状态完全等价。
- 重置重建模型并清零耗散功与时间，多次重置初始条件不漂移。
- 记录器对相邻采样做速度/角度跳变校验，保证回放关键状态不跳变。
- 摩擦耗散功与机械能损失逐项配平，温升由耗散功经等效比热容换算。

## 三类验证工况（见 `tests/run-tests.mjs`）

- 正常工况：无摩擦 5 s 能量漂移 < 0.1%；摩擦开启能量衰减、耗散配平、温升为正。
- 极限载荷：50 kg、1 m、150° 摆球越过 1500 N 压力上限即停止并冻结，触发后不再计算。
- 失稳：大角度双摆进入混沌高速，触发速度/边界/压力限值并完整记录触发点状态。

## 目录

- `src/physics/`：RK4 积分器、单摆与双摆模型（能量、压力、温度）。
- `src/simulation/`：运行器、限值监测、轨迹记录器、模型工厂。
- `src/ui/`：Canvas 渲染器、Web Audio、导出、界面控制器。
- `tests/`：物理验证与 DOM 交互冒烟测试。
